# Artwork

The cover in `public/cover.png` was generated using the built-in image generation tool and copied into the project. It is used as home-screen key art. In-game world art and animated character drawings are procedural Phaser graphics, so there are no external sprite downloads or missing texture files.

## Final cover prompt

Use case: stylized-concept. Asset type: polished wide 16:9 browser game cover and home screen artwork. Create a colourful modern cartoon adventure island for a multiplayer treasure-hunting game called Treasure Rush. Gorgeous stylized 3D illustration, sunny tropical turquoise ocean, lush small island, curved sandy paths, ancient stone ruin arch, palm trees, glowing open treasure chest overflowing gold coins and teal diamonds in foreground, three charming distinct tiny adventurers (coral jacket fox explorer, teal frog scout, purple raccoon pirate) racing toward treasure. Golden sunlight, vivid teal and coral, rich navy shadows, premium indie game key art, carefully composed and readable at small sizes. Put scene focal objects on right two thirds, quieter dark turquoise sea on left for HTML headline overlay. No text, letters, logos, watermark or UI.

## Fonts

The interface requests DM Sans and Outfit from Google Fonts and falls back to installed sans-serif fonts if unavailable. Georgia is used for the italic adventure accent. Character selection uses platform emoji; the in-game explorers use custom vector drawing code with six different color/ear silhouettes.
